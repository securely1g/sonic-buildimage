# Debian metadata for source-built packages

The package directories and `manifest.json` are **auto-generated. Do not edit
them manually**. `capture.py` extracts control files from existing, reviewed
Make-built DEBs. It does not build DEBs, install packages, or run maintainer
scripts. The ordinary Bazel build consumes these checked-in text files.

The manifest records each reference package's filename, SHA-256, version and
architecture, plus the original SHA-256 and permissions of every control file.
Script bytes are retained exactly, including the sections generated by Debian's
`debhelper` packaging tools. For example, the four Syncd installation and removal
scripts are generated by `dh_installinit`; copying only files from the source
repository's `debian/` directory would omit them.

These controls supply package relationships, configuration-file declarations,
installation/removal scripts, library metadata and trigger declarations. A
trigger requests deferred work from another package; shared libraries request
`ldconfig` to refresh the dynamic linker's library cache. File ownership lists,
checksums and configuration-file hashes must be generated from the actual
source-built payload, not copied from the old binary packages.

Keeping a `postinst` script records how future package operations should behave.
It does **not** prove that the image has already performed the script's initial
installation work. Image assembly must also account for required users,
alternatives, generated files and trigger state, with package-manager operations
validated in the completed images.

## Refresh the captured files

Use the exact reviewed Make packages whose versions match the image contracts.
For the original capture, the 22 base/config-engine packages also matched the
installed control files in the retained Make config-engine image:

- OCI manifest: `sha256:2afbbccd9008c7670fd1adbc5349f4a65c76b7b7d224f1a3867c1fd3aa79978d`
- `/var/lib/dpkg/status` SHA-256: `3d5315c48d56d51528403cea7380fbda8440395ab2c1e56189db311477dd21f6`

From the repository root:

```sh
python3 tools/bazel/dpkg/source_controls/capture.py \
  --deb-dir "$MAKE_CHECKOUT/target/debs/trixie" \
  --contract dockers/docker-base-trixie/bazel/source_packages.json \
  --contract dockers/docker-config-engine-trixie/bazel/source_packages.json \
  --contract platform/vs/docker-syncd-vs/config/source_packages.json \
  --extra-deb "$MAKE_CHECKOUT/target/debs/trixie/swss_1.0.0_amd64.deb" \
  --extra-deb "$MAKE_CHECKOUT/target/debs/trixie/libdashapi_1.0.0_amd64.deb" \
  --extra-deb "$APT_INPUTS/libprotobuf32t64_3.21.12-11+deb13u1_amd64.deb"
```

The Protobuf reference is the existing Debian package selected by Orchagent's
checked APT lock. Its SHA-256 is
`38c43ec79a043d2b2659fed321725049a7e457096a66691cf6eb0d3a1a8f0e85`.
Review every metadata change when refreshing. A source change that alters the
package's installation or removal behavior must update these inputs too.

## Native architectures and source versions

The captured package architecture describes the reference archive. The image
records the actual architecture of its source-built payload. SymCrypt's original
package says `all`, despite containing native libraries; its final image record
must use the native architecture.

The only architecture-specific script text in these controls is the package
qualifier `python3-libyang:amd64` in the Python installation and removal scripts.
The manifest explicitly allows replacing that exact qualifier with the selected
native architecture. Original file bytes and hashes remain unchanged in Git;
the image builder records the rendered result separately. Do not perform broad
architecture substitutions in arbitrary control files.

Protobuf's source owner builds upstream `v21.12` with the registry's Bazel
integration patch. Its image version is therefore `3.21.12+sonic.1`. The manifest
explicitly permits borrowing lifecycle metadata from Debian
`3.21.12-11+deb13u1`, while preserving both version identities and source
provenance. This does not claim that Debian's additional source patches are
present in the Bazel-built library.
