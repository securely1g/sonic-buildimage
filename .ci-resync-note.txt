CI re-sync marker
=================

Purpose: force GitHub to advance the PR #26724 head pointer.

Context:
- GitHub PR #26724 .head.sha was stuck on stale commit e80b2619
  (sonic-redfish submodule = c11fe4ee, which fails aspeed_arm64 bmcweb
  build due to an upstream sdbusplus breaking change:
  sdbusplus::message::object_path was removed/renamed to sdbusplus::object_path).
- The csonic2 branch already contains the fix: sonic-redfish bumped to
  8b41b27 (commit fc98dffb1), which compiles cleanly on arm64.
- The fork branch refs/heads/csonic2 was already at the fixed tip, but
  GitHub's PR head ref did not advance (no-op pushes do not refresh it).

A brand-new commit on the branch tip forces GitHub to re-evaluate the PR
head and re-run CI on the corrected tree.
